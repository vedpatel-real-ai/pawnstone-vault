# Claim matrix

| Claim | What the regression checks | Boundary |
|---|---|---|
| Only the scheduler can initiate privileged assessment | Rejected method, bad or missing secret, and incomplete configuration leave the injected work callback untouched. The real local Edge endpoint rejects anonymous calls with identical pre/post financial state. [Handler tests](../../src/lib/scheduler.test.ts) · [Edge test](../../tests/integration/edge.test.mjs) | Local gateway and Deno runtime. Hosted configuration must be checked at deployment. |
| A shop can access only its records | Two confirmed synthetic accounts exercise Auth, membership, PostgREST reads/writes and restricted RPCs. Each of nine tables is examined. [Tenant tests](../../tests/integration/tenants.test.mjs) | Specific ordinary roles, generated schema and local project configuration. Service-role credentials are privileged. |
| Private object operations follow parent ownership | Upload, overwrite, signing, download and removal are checked for customer and loan folders. [Storage tests](../../tests/integration/tenants.test.mjs) | A valid signed URL remains usable until expiration. |
| Collections reconcile under concurrency and retry | ₹1,000 − ₹100 − ₹200 leaves ₹700 and two receipts. Equal retry IDs return the same receipt. An excessive interest allocation rolls back. [Posting tests](../../tests/integration/ledger.test.mjs) | Independent API requests against one local PostgreSQL database. New request IDs represent new intents. |
| Partial payments preserve open balances | ₹1 of a ₹20 invoice leaves ₹19 and an open due. Full closure waits for principal and interest. [Database tests](../../tests/integration/ledger.test.mjs) · [Demo tests](../../src/data/demo/ledger.test.ts) | Monthly simple interest, principal receipts, and separately recorded fees. |
| Dues generation survives retries | Competing runs produce unique invoices and notices. An injected insert failure leaves the schedule untouched. A subsequent run catches up. [Job tests](../../tests/integration/scheduler.test.mjs) | Local SQL transactions. Actual cron configuration is external. |
| External mail goes through a controlled attempt | Concurrent claims select the same notice only once. A fake transport distinguishes acceptance, rejection and uncertainty. [Claim tests](../../tests/integration/scheduler.test.mjs) · [Transport tests](../../src/lib/dueMail.test.ts) | No real email, provider account or inbox delivery test. |
| Private business records stay out of the offline cache | The service worker passes private requests through, retires its legacy cache and caches public build assets. The remote UI requires connectivity. [Worker tests](../../src/lib/serviceWorker.test.ts) · [Chromium tests](../../tests/offline.spec.ts) | Service-worker Cache Storage. Downloaded reports and demo data reside on the device. |
| An operator sees the correct directory after changing accounts | Two synthetic accounts use the same browser context and real local Auth, with a sign-out between them. [Session test](../../tests/integration/session.test.mjs) | Local Supabase mode in Chromium. |
| Installation and upgrade are repeatable | Two clean CLI resets and a versioned upgrade with an existing synthetic loan, receipt and paid due. [Verifier](../../scripts/verify.py) · [Fixture](../../scripts/upgrade-fixture.mjs) | One representative legacy history. Manual drift and inconsistent production records require staging reconciliation. |
| The dashboard and reports reflect queried data | The demo flow posts interest and principal, then checks the invoice and monthly interest KPI. Chromium downloads a loan CSV and PDF. [Collections workflow](../../tests/e2e.spec.ts) · [Report test](../../tests/offline.spec.ts) | Query refresh, file signatures and payload checks. No live subscription or performance benchmark. |
